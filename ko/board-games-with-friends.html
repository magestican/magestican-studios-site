Magestican Studios › 친구와 함께하는 보드게임

친구와 무료로, 계정 없이 즐기는 온라인 보드게임

게임판은 탁자 위에 있지만 친구는 다른 도시에 있어요. 브라우저 탭에서 바로 즐길 수 있는 클래식 보드게임 네 가지가 있어요. 방을 만들고 링크를 보내면, 서로 다른 컴퓨터나 휴대폰에서 같은 판을 함께 볼 수 있어요. 가입도, 설치도, 광고도, 시계도 없어요.

  • 링크로 바로 참여
  • 서로 다른 컴퓨터
  • 시계 없음
  • 광고 없음

보드게임 목록

  • Farmy Tiles

    정식 15x15 보드에서 즐기는 단어 타일 게임으로, 실제와 같은 100개짜리 타일 주머니와 보너스 칸을 갖췄어요.

    2~4명이 하나의 보드에서 플레이하거나 컴퓨터와 대결할 수 있어요. 링크로 초대하고 계정은 필요 없어요.

  • Farmy Chess

    완전한 체스예요. 캐슬링, 앙파상, 승진, 모든 무승부 규칙까지 갖췄어요. 크고 대비가 뚜렷한 말, 시계 없음.

    2인용이거나 내 실력에 맞춰주는 컴퓨터와 대결할 수 있어요. 링크로 초대하고 계정은 필요 없어요.

  • Farmy Checkers

    영국식 체커예요. 양 열두 마리와 소 열두 마리가 맞서고, 잡기는 필수이며, 연속 점프와 킹 승급까지 있어요.

    2인용이거나 내 실력에 맞춰주는 컴퓨터와 대결할 수 있어요. 링크로 초대하고 계정은 필요 없어요.

  • Farmy Ludo

    네 개의 농장 팀이 있고, 6이 나와야 출발할 수 있고 정확한 숫자가 나와야 도착해요. 각 팀마다 색뿐 아니라 고유한 모양도 있어요.

    최대 네 명까지 플레이할 수 있고, 아무도 선택하지 않은 팀은 컴퓨터가 대신 맡아요. 링크로 초대하고 계정은 필요 없어요.

친구 성향에 맞는 게임 고르기

  • 진지하게 즐기고 싶은 친구라면: Farmy Chess는 캐슬링, 앙파상, 승진, 모든 무승부 규칙까지 갖춘 완전한 체스예요. 2인용이고, 아무도 없을 땐 컴퓨터가 내 실력에 맞춰 상대해 줘요.
  • 좀 더 빠른 게임을 원하는 친구라면: Farmy Checkers는 영국식 체커예요. 양 열두 마리와 소 열두 마리가 맞서고, 잡을 수 있으면 반드시 잡아야 하며, 여러 번 연속으로 넘을 수 있고, 반대편 끝에 도달한 말은 킹이 돼요.
  • 가족 단체 채팅방이라면: Farmy Ludo는 최대 네 명이 즐겨요. 6이 나와야 출발할 수 있고 정확한 숫자가 나와야 집에 들어갈 수 있는데, 예전 식탁 위에서 하던 것만큼이나 얄짤없어요. 팀마다 색뿐 아니라 모양도 있어서 빨강과 주황을 헷갈릴 일도 없어요.
  • 단어를 좋아하는 친구라면: Farmy Tiles는 15x15 정식 크로스워드 타일 게임이에요. 실제와 같은 100개짜리 타일 주머니, 보너스 칸, 일곱 개 타일을 모두 쓰면 주어지는 50점 보너스까지 갖췄어요. 2~4인용이거나 컴퓨터와 대결할 수도 있어요.

다른 컴퓨터에 있는 친구와 게임을 시작하는 방법

  1. 게임 페이지를 열고 플레이를 누르세요. 게임판이 탭에 바로 나타나고, 아무것도 설치되지 않아요.
  2. 친구와 플레이하기를 선택하고 방을 만드세요. 링크가 생성돼요.
  3. 평소에 쓰는 방법대로 링크를 보내세요. 문자, 이메일, 단체 채팅, 영상 통화 채팅창 모두 괜찮아요.
  4. 친구가 노트북, 크롬북, 태블릿, 휴대폰 등 브라우저에서 링크를 열면 바로 자리에 앉게 돼요.

두 사람 모두 계정을 만들 필요가 없어요. 두 브라우저가 직접 연결되기 때문에 게임을 저장하는 서버도 없어요. 말은 크고 뚜렷해서 휴대폰에서도, 시력이 예전 같지 않은 분에게도 편해요.

질문

가입 없이 친구와 체스 온라인 2인용으로 즐길 수 있나요?

네, 가능해요. Farmy Chess를 열고 방을 만든 뒤 링크를 보내세요. 친구가 브라우저에서 링크를 열면 같은 판을 함께 보게 돼요. 두 사람 모두 계정을 만들 필요가 없어요.

루도는 몇 명이 함께 온라인으로 플레이할 수 있나요?

최대 네 명까지, 각자의 기기에서 하나의 링크로 참여할 수 있어요. 아무도 선택하지 않은 팀은 컴퓨터가 대신 맡아서, 두세 명이어도 완전한 게임을 즐길 수 있어요.

시계나 타이머가 있나요?

없어요. 네 가지 보드게임 모두 시계가 없어서 시간 때문에 지는 일은 없어요.
