Magestican Studios › Zelakas In Space

Game Flash tahun 2014 yang tidak pernah benar-benar mati. Mainkan Zelakas In Space di browsermu.

Hindari asteroid, lubang hitam, dan drone dalam game tembak-tembakan arcade 2D gratis ini. Tiga akhir cerita, ditentukan seberapa banyak medan yang kamu bersihkan. Tanpa plugin, tanpa download, tanpa akun — file SWF asli berjalan di dalam browser modern lewat emulator Ruffle.

Butuh keyboard. Desktop atau laptop — game ini lebih tua dari zaman touchscreen.

Tiga akhir cerita

Bersihkan medan sampai batas tertentu dan permainan akan berakhir secara berbeda. Kebanyakan pemain hanya melihat akhir cerita pertama dan tidak pernah tahu masih ada dua lagi.

Tanpa Flash Player

Flash resmi mati tahun 2020. Ruffle — emulator Flash open-source yang dikompilasi ke WebAssembly — menjalankan file aslinya dengan aman, tanpa plugin yang perlu diinstal.

Gratis, tanpa akun

Tanpa daftar akun, tanpa iklan, tanpa launcher.

Masalah yang sudah kami ketahui, dan kami lebih suka kamu mendengarnya langsung dari kami. File Flash asli tahun 2014 berjalan lewat Ruffle, dan saat ini baru sampai layar judul dan pilihan kesulitan, lalu berhenti di loading bar saat kamu menekan PLAY. File yang kami sajikan adalah file asli, byte demi byte; masalahnya ada di emulatornya. Sedang kami perbaiki.

Dibuat tahun 2014

Dibuat dengan ActionScript 3 oleh Bryan Arbelo bersama Gonzalo dan Christian. Game ini dilestarikan di sini persis seperti saat dirilis, lengkap dengan bug-bugnya.

Versi remake sedang dalam pengerjaan

Versi port native Godot 4 ada di repo workshop terbuka milik studio. Versi Flash tetap dipertahankan online — pelestarian tetap jadi yang utama.

Digambar tangan

Setiap pesawat, batu, dan drone dalam game ini digambar tangan oleh seseorang pada 2014. Game yang kami buat sekarang justru menghasilkan sebagian besar aset visualnya lewat kode, dan standar yang kami pegang untuk setiap aset adalah hasil akhirnya, bukan alat yang dipakai: harus jelas dalam siluet, cocok dengan palet warna, dan tidak kalah dibanding aset lain yang tampil di sebelahnya.

Pertanyaan yang sering diajukan

Apakah saya perlu Flash Player?

Tidak. Flash Player sudah dihentikan sejak 2020 dan tidak ada browser yang bisa menjalankannya lagi. Halaman ini memuat file ZelakasInSpace.swf aslinya lewat Ruffle, emulator Flash open-source yang ditulis dengan Rust dan dikompilasi ke WebAssembly. Ia berjalan di sandbox milik halaman itu sendiri; tidak ada yang diinstal.

Apakah gratis?

Ya — gratis, tanpa iklan, tanpa daftar akun.

Ada berapa akhir cerita?

Ada tiga, ditentukan oleh seberapa banyak medan yang kamu bersihkan sebelum permainan berakhir.

Apa saja kontrolnya?

Hanya keyboard: tombol arah untuk terbang, tombol tembak untuk menembak. Game desktop tahun 2014 memang punya kontrol desktop tahun 2014. Kalau kamu ingin sesuatu yang jalan di ponsel, Splatbarn Uprising punya kontrol sentuh bawaan.

Apakah bisa jalan di laptop kantor saya?

Kalau browsernya bisa terbuka, bisa. Tidak ada installer dan tidak perlu hak admin — lihat game tanpa download untuk komputer kantor.

Apakah data saya dikumpulkan?

Tanpa akun, tanpa profil, tanpa iklan. Kami hanya menghitung kunjungan halaman secara anonim dan tanpa cookie, supaya kami tahu game mana yang ditemukan orang-orang. Lihat kebijakan privasi.
