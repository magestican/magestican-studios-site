Zelakas In Space

Original 2014 Flash build · Bryan Arbelo · Gonzalo · Christian · running in-browser via Ruffle

Flash Player was end-of-lifed in 2020. This page loads the original ZelakasInSpace.swf through Ruffle, an open-source Flash emulator written in Rust. A native Godot 4 port of the game lives under games/zelakas-in-space/ in this repo.
